# Raseen (رسين) — نظام الفواتير والمحاسبة وهيئة الزكاة (Go)

نظام عربي مبني بلغة **Go (Golang)**؛ يشغّل `raseen.exe` الواجهة والخادم، ويحفظ قاعدة SQLite وقوالب HTML في مجلد `data` المجاور للملف التنفيذي. يجب تسليم `data/templates` مع البرنامج حتى تعمل الطباعة.

---

## 🚀 المميزات الرئيسية

- **تشغيل محلي (`raseen.exe` مع `data/`)**: واجهة الويب مدمجة في الملف التنفيذي، بينما تبقى قاعدة البيانات والقوالب في مجلد البيانات لتسهيل النسخ الاحتياطي والاستيراد.
- **مستندات الفوترة الإلكترونية والتوقيع المحلي** (اعتماد التكامل الإنتاجي مع ZATCA يحتاج تحققًا منفصلًا):
  - فواتير ضريبية قياسية ومبسطة (B2B و B2C).
  - تشفير QR TLV المعتمد للـ Phase 1 و Phase 2.
  - تجزئة الفاتورة (Invoice Hashing عبر SHA-256) وسلسلة التحقق (Hash Chaining).
  - توقيع رقمي ECDSA وتوليد ملفات XML المتوافقة مع معيار UBL 2.1.
- **إدارة الشركات والعملاء والأصناف**:
  - دعم شركات متعددة (Multi-Issuer) في برنامج واحد.
  - دليل العملاء وحدود الائتمان والأرصدة الافتتاحية.
  - دليل الأصناف والمجموعات ونسب الضريبة.
- **المحاسبة وسندات القبض ودفتر الأستاذ**:
  - سندات قبض مع تخصيص آلي أو يدوي للدفعات على الفواتير.
  - كشف حساب العميل (Statement of Account) تفصيلي لحظي.
  - تقارير أعمار الذمم (Aging Report)، ضريبة القيمة المضافة، والمبيعات الشهرية.
- **استيراد وتوليد الإكسل الذكي**:
  - قراءة ملفات XLSX و CSV تلقائياً واكتشاف صف العناوين والمرادفات العربية والإنجليزية.
  - تحميل نماذج إكسل جاهزة للاستيراد السريع.
- **أمان ونسخ احتياطي**:
  - تشفير كلمات المرور وحماية الجلسات.
  - نسخ احتياطي بنقرة واحدة لقاعدة البيانات.

## 💻 دليل وتعليمات التشغيل

### 1. التشغيل المباشر (الملف التنفيذي `raseen.exe`):

#### أ) بنقرة واحدة (واجهة المستخدم):
1. افتح مجلد المشروع `Raseen` في ويندوز.
2. انقر نقراً مزدوجاً (**Double-click**) على ملف **`raseen.exe`**.
3. سيبدأ الخادم بالعمل فوراً، وسيفتح متصفح الويب تلقائياً على الرابط:
   👉 **`http://127.0.0.1:4711`**

#### ب) من خلال الطرفية (PowerShell أو CMD):
```powershell
.\raseen.exe
```

---

### 2. التشغيل من كود Go المصدري (للمطورين):

إذا كنت ترغب بتشغيل البرنامج مباشرة من الكود المصدري دون الاعتماد على الملف التنفيذي:
```powershell
go run .
```

---

### 🔑 بيانات تسجيل الدخول الأولية:

عند فتح صفحة النظام في المتصفح، استخدم بيانات الدخول الافتراضية:

- **اسم المستخدم:** `admin`
- **كلمة المرور:** `Admin@12345`

> **ملاحظة أمان**: يُنصح بتغيير كلمة المرور فور أول تسجيل دخول من خلال الإعدادات أو شريط المستخدم العلوي.

---

### ⚙️ خيارات وبيئة التشغيل (اختياري):

يمكنك تخصيص إعدادات التشغيل عبر متغيرات البيئة قبل تنفيذ الأمر:

- **تغيير المنفذ (Port)**:
  ```powershell
  $env:PORT = "5000"; .\raseen.exe
  ```
- **تشغيل في الخلفية بدون فتح المتصفح تلقائياً**:
  ```powershell
  $env:NO_BROWSER = "1"; .\raseen.exe
  ```
- **تحديد مسار مخصص لمجلد البيانات**:
  ```powershell
  $env:ZS_DATA_DIR = "D:\RaseenData"; .\raseen.exe
  ```

## ☁️ النشر السحابي على منصة Railway (وحماية البيانات)

النظام مهيأ وجاهز للتشغيل مباشرة على منصة **Railway** السحابية عبر Docker أو Nixpacks.

قبل تشغيل الخدمة على عنوان عام، اضبط متغير البيئة `ZS_ADMIN_PASS` على كلمة مرور قوية وفريدة. يسجل الخادم تحذيرًا إذا بقيت كلمة المرور الافتراضية. إذا كانت قاعدة البيانات قد استُخدمت سابقاً، غيّر كلمة مرور حساب المدير من داخل النظام أيضاً؛ تغيير متغير البيئة وحده لا يغيّر كلمات المرور المخزنة. لتحديث خدمة موجودة مع الحفاظ على بياناتها، اتبع [دليل تحديث Railway](DEPLOY-RAILWAY.md).

### ⚠️ خطوة أساسية وإلزامية: إضافة قرص تخزين دائم (Persistent Volume)
السيرفرات السحابية تقوم بإعادة إنشاء الحاوية (Container) عند كل تحديث أو رفع كود جديد. **لضمان بقاء قاعدة البيانات والفواتير والعملاء محفوظة بشكل دائم ولا تُحذف عند التحديث**، يجب إضافة قرص تخزين دائم باتباع الخطوات التالية:

1. في لوحة تحكم مشروعك على **Railway** (الشاشة الرئيسية المنقطة Canvas):
   - اضغط **كليك يمين (الزر الأيمن للفأرة)** في أي مكان فارغ، أو اضغط علامة **`+`**.
2. اختر من القائمة: **`Volume`**.
3. في نافذة إنشاء الـ Volume:
   - اربطه بخدمة **`Raseen`**.
   - في خانة مسار التثبيت (**Mount Path**)، اكتب بالضبط:
     ```text
     /app/data
     ```
   - اضغط **`Enter`** أو **`Add`**.
4. اضغط على الزر البنفسجي في أعلى الشاشة: **`Deploy`** (أو `Apply changes`) لتطبيق التغيير.

> [!IMPORTANT]
> بعد ربط الـ Volume بمسار `/app/data`، تصبح قاعدة بيانات SQLite (`zsystem.db`) والنسخ الاحتياطية السحابية محفوظة في قرص تخزين دائم لا يتأثر بأي إعادة نشر أو تحديث مستقبلي للكود.

## 💾 النسخ الاحتياطي واستيراد/تصدير الحزمة والقوالب (.zip / .db)

1. **تصدير حزمة النظام الشاملة (.zip)**:
   - من شاشة **«الإعدادات»** (لحساب المدير ADMIN):
     - اضغط **«تصدير حزمة النظام الشاملة (.zip)»** لتنزيل ملف مضغوط متكامل يحتوي على:
       - نسخة متناسقة ولحظية من قاعدة البيانات بالكامل (`zsystem.db`).
       - كافة قوالب الفواتير والسندات الـ 39 وملفات HTML المخصصة.
       - رمز العملة وملف التعريف `manifest.json`.
   - تتضمن الحزمة ملف `secret.key` اللازم لنقل بيانات الاعتماد المشفرة. تعامل مع ملف ZIP كنسخة حساسة من قاعدة البيانات ومفاتيحها، واحفظه في مكان آمن.
     - يتوفر أيضاً خيار **«تنزيل قاعدة البيانات فقط (.db)»** لمن يرغب في استخراج ملف SQLite فقط.

2. **استيراد واستعادة الحزمة والقوالب (.zip أو .db)**:
   - اضغط **«استيراد واستعادة الحزمة / القوالب»**:
     - يدعم رفع ملف مضغوط **`.zip`** يحتوي على مجلد البيانات والقوالب وقاعدة البيانات ليتم استعادتها وتحديث دليل القوالب فوراً.
     - يدعم رفع ملف مضغوط **`.zip`** يحتوي فقط على قوالب HTML (لتحديث وإضافة القوالب دفعة واحدة دون المساس بالفواتير الحالية).
     - يدعم رفع ملف قاعدة بيانات منفرد **`.db`**.
   - **حماية وقائية تلقائية**: يقوم النظام قبل أي عملية استيراد بأخذ نسخة احتياطية وقائية تلقائياً على السيرفر لضمان عدم فقدان أي بيانات سابقة.

3. **النسخ الاحتياطي التلقائي (Auto-Backup)**:
   - يقوم محرك رسين تلقائياً بأخذ نسخة احتياطية كاملة ومفهرسة بالتاريخ والوقت عند كل تشغيل، ثم كل 24 ساعة بشكل دوري مستمر في مجلد:
     `data/backups/`
   - تحفظ كل نسخة ملف قاعدة بيانات `.db` وملف مفتاح مطابق `.key` بالاسم نفسه. احتفظ بالملفين معاً في مكان آمن لاستعادة بيانات الاعتماد المشفرة.

## 🛠️ البناء من المصدر (Build)

يتطلب بيئة Go 1.26 أو أحدث:

```bash
# بناء البرنامج كملف تنفيذي مصغّر لويندوز
go build -ldflags="-s -w" -o raseen.exe .

# بناء البرنامج لأنظمة لينكس / الحاويات السحابية
GOOS=linux GOARCH=amd64 go build -ldflags="-s -w" -o raseen .
```
