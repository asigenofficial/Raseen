# Raseen (رسين) — نظام الفواتير والمحاسبة وهيئة الزكاة (Go)

نظام عربي مستقل فائق السرعة مبني بلغة **Go (Golang)**، يعمل كملف تنفيذي واحد مدمج (`raseen.exe`) يجمع محرك الفواتير وهيئة الزكاة والضريبة (ZATCA)، دفتر الأستاذ وكشوف الحساب، واستيراد الإكسل، وقاعدة بيانات SQLite مدمجة بدون الحاجة لتثبيت خوادم أو أي برامج وسيطة.

---

## 🚀 المميزات الرئيسية

- **ملف تنفيذي مستقل واحد (`raseen.exe`)**: مدمج بداخله واجهة الويب كاملة وقاعدة البيانات، لا يتطلب تثبيت Node.js ولا قواعد بيانات خارجية.
- **امتثال كامل لهيئة الزكاة والضريبة والجمارك (ZATCA)**:
  - فواتير ضريبية قياسية ومبسطة (B2B و B2C).
  - تشفير QR TLV المعتمد للـ Phase 1 و Phase 2.
  - تجزئة الفاتورة (Invoice Hashing عبر SHA-256) وسلسلة التحقق (Hash Chaining).
  - توقيع رقمي ECDSA وتوليد ملفات XML المتوافقة مع معيار UBL 2.1.
- **إدارة الشركات والعملاء والأصناف**:
  - دعم شركات متعددة (Multi-Issuer) في برنامج واحد.
  - دليل العملاء وحدود الائتمان والأرصدة الافتتاحية.
  - دليل الأصناف والمجموعات ونسب الضريبة.
- **المحاسبة وسندات القبض ودفتر الأستاذ**:
  - سندات قبض مع تخصيص آلي أو يدوي للدفعات على الفواتير.
  - كشف حساب العميل (Statement of Account) تفصيلي لحظي.
  - تقارير أعمار الذمم (Aging Report)، ضريبة القيمة المضافة، والمبيعات الشهرية.
- **استيراد وتوليد الإكسل الذكي**:
  - قراءة ملفات XLSX و CSV تلقائياً واكتشاف صف العناوين والمرادفات العربية والإنجليزية.
  - تحميل نماذج إكسل جاهزة للاستيراد السريع.
- **أمان ونسخ احتياطي**:
  - تشفير كلمات المرور وحماية الجلسات.
  - نسخ احتياطي بنقرة واحدة لقاعدة البيانات.

## 💻 التشغيل السريع

### تشغيل البرنامج فوراً:
فقط انقر نقراً مزدوجاً على ملف `raseen.exe` (أو نفذه من الطرفية):

```bash
.\raseen.exe
```

سيفتح النظام المتصفح تلقائياً على الرابط: `http://127.0.0.1:4711`

### بيانات تسجيل الدخول الافتراضية:
- **اسم المستخدم:** `admin`
- **كلمة المرور:** `Admin@12345`

## 🛠️ البناء من المصدر (Build)

يتطلب بيئة Go 1.22 أو أحدث:

```bash
# بناء البرنامج كملف تنفيذي مصغّر
go build -ldflags="-s -w" -o raseen.exe .

# تشغيل الاختبارات
go test -v ./test/...
```
